# Strategic Architecture & Phased Roadmap

1. **Phase 1 (MVP)**: Core loop of 6 primary data entities (`Mission`, `Task`, `Agent`, `Worker`, `ToolCall`, `Artifact`) with Gemini model routing and Firestore persistence.
2. **Phase 2**: Knowledge repository compounding, automated code synthesis, and structured growth loops.
3. **Phase 3**: Autonomous deployment validation, external tools integration, and founder approval workflows.
